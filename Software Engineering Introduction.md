Software engineering is the application of engineering to the development of software. It provides a systematic discipline to design development operations and maintenance of software, ensure the software is delivered on time within budget, reliable, efficient and maintainable.


# Software Components
### User Interface
The part of the software through which the user interacts. For example: dashboard.
It must be user friendly.
### Business Logic
Core functionality of the software implements rules, operations and decision making. For example: Calculating bills.
### Database(Data layer)
Responsible for storing and retrieving data. Can be relational SQL, and non-relational SQL. In short, security and integrity of data. For example: Instagram database.
### Integration Components
Connects different software systems and act as a bridge between applications. For example:
Google maps API.
### System Infrastructure Components
Supporting services like operating system, network and security tools. Ensure the software runs efficiently in different environments. Example: OS. Network, Cloud.

# Software Characteristics

### Correctness
A software must always produce the expected results. It should perform it's functions exactly as required.


It should not crash. Example: Banking software must be reliable otherwise user may lose trust. 

### Efficiency
CPU, memory, while giving fast results. It should not make the system slow. Example: Google search shows results in a fraction of a second.
